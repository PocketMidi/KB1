## Hardware

* This folder contains the electronic and mechanical hardware files for building and assembling the KB1.
* For further reference check out the [hardware reference](../references/hardware) folder.

* [Assembly guide](KB1_assembly_guide.pdf)
* [Electronics](electronics/README.md): PCB, schematics, Gerbers, and BOM.
* [Mechanicals](mechanicals/README.md): Printable enclosure parts and desktop stand.
* [KB1 Studio User Guide](https://pocketmidi.github.io/KB1-studio/): Current operating and charging instructions.
